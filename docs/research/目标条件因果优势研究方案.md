# 目标条件因果优势：长程 Agent 局部决策的反事实评估

## 摘要

本研究关注长程软件工程 Agent 的一个核心问题：局部动作看似完成当前子任务时，如何判断它是否仍然促进最终目标。我们提出目标条件因果优势（GCCA），在固定后续策略下比较“执行当前行动”与“执行替代行动”对终局效用的干预差异。方法同时纳入真实执行反馈带来的信念更新、信息价值、成本和不可逆风险。

## 方法

对目标 `G`、信念状态 `b_t`、当前行动 `a` 和替代行动 `a'`，定义：

```text
GCCA_t(a, a'; G)
  = E[Y_G | do(A_t=a), b_t, pi_c]
  - E[Y_G | do(A_t=a'), b_t, pi_c]
```

在线控制使用：

```text
J_t(a) = GCCA_hat_t(a) + lambda*EVI_t(a)
         - alpha*Cost_t(a) - beta*IrreversibilityRisk_t(a)
         - gamma*ConstraintRisk_t(a)
```

这里的因果结论严格限于相同初始快照、候选行动集合和固定后续策略下的干预效应；它不声称能从任意自然语言轨迹无条件恢复真实因果关系。

## 实验设计

对照包含局部进展、普通目标价值、因果优势和完整方法。可控层从相同代码快照分出行动分支，得到反事实近似真值；真实层以任务和随机种子为区组随机分配方法。共同主要终点是最佳行动命中率与最终任务成功率，并报告 GCCA 均方误差、错误路线长度、重规划时机、约束违规、token 和墙钟成本。

## 已验证证据

截至 2026-09-21，仓库已实现并通过确定性测试：场景契约、反事实优势计算、四种评分接口、快照污染检测、中文报告和 DeepSeek 密钥/usage 门禁。`DQ-DIAGNOSE-001` 已改为可执行的受控反事实夹具：三个行动在同一初始快照的独立副本运行，再由固定后续策略和独立判定器计算 `1/0/0` 的终局效用。一次 `deepseek-chat` 配对冒烟中，完整方法选择诊断路径并命中最佳行动，消耗 387 token；详见[运行记录](../../results/2026-09-21-live-paired-counterfactual.md)。这只是一个夹具和一次调用，不能作为方法优越性的统计结论。
