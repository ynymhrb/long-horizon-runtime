# 目标条件因果优势评测：面试手册

## 30 秒介绍

我围绕长程 Agent 的目标漂移问题，设计了一个决策评测系统。它不把子任务完成当作进展，而是在真实执行反馈更新后的状态上，比较当前行动和替代行动对最终目标的反事实贡献。工程上我用隔离代码快照执行候选行动分支，并用独立 oracle、哈希化证据和成本门禁验证结论；当前已经完成确定性链路验证，真实模型对照仍按预注册计划进行。

## 2 分钟介绍

长程 Agent 往往会陷入“局部正确、全局失败”：一个补丁能通过当前测试，却破坏回归；或者持续修复已经被新证据否定的假设。我将问题建模为部分可观测的序贯因果决策：Agent 维护对真实项目状态的信念，基于测试、构建和静态分析反馈更新它，并估计当前行动相对替代行动的终局效用差，即 GCCA。

最难的是不能把模型自评当作真值。因此我把评测分成两层：可控层在同一初始快照上实际执行多个候选行动，固定后续策略以隔离当前决策；真实层再用配对随机对照检验控制策略是否提高最终成功率。系统还把信息价值、成本、不可逆性和约束风险纳入分数，因此不确定时倾向可逆诊断而不是高风险修改。

目前可验证的结果包含一次预注册的受控配对试验：12 场景、4 方法、48 个完整单元，累计 18,432 token。因果优势评分在该分布中命中 8/12 个最佳行动，其他三种方法各为 6/12。我要明确说明：这些任务共享受控状态机引擎，结果只说明评测链路和该任务分布上的条件性现象，不能称为生产仓库效果或统计显著提升。

## 三项工程决策

1. **固定后续策略。** 问题是后续 Agent 行为会混入当前行动的效果；选择固定 `pi_c` 以隔离边际干预效应。代价是结论对策略敏感，后续要做策略稳健性实验。
2. **分支快照而非日志相关性。** 问题是历史轨迹存在选择偏差；选择对同一快照执行替代行动。代价是计算昂贵，因此真实层只在关键决策点使用，并用离策略估计做辅助。
3. **证据缺失即不确定。** 问题是模型 usage、oracle 或分支结果缺失时很容易产生伪精确结论；选择 `inconclusive`，不做零值填补。代价是有效样本量降低，但可审计性更高。

## 高频追问

**为什么不是普通 Q 值？** Q 值可排序长期收益，但不区分“行动后成功”和“该行动导致成功”。GCCA 通过显式替代行动和干预比较，把问题改成边际贡献。

**反事实如何获得？** 可控任务在同一快照分支实际执行，不能遍历的真实任务仅报告有识别条件的估计和置信区间。

**如何避免更高 token 带来假提升？** 所有方法固定模型、工具和预算，报告 token、墙钟和工具调用；正确性优先于成本，但不会隐藏成本。

**什么能推翻你的方法？** 排序不优于普通价值、排序不转化为成功率、去掉执行反馈后无变化、或换后续策略后排名反转，都能推翻相应假设。
