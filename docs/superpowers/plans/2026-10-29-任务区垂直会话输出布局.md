# 任务区垂直会话输出布局实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 将长任务驾驶舱改为顶部限高的非模态面板，保留下方当前会话原生实时输出。

**架构：** 保留 `shell.overlay` 注册和任务数据加载逻辑，但移除全屏遮罩。`TaskArea` 为打开状态标记顶部面板，样式控制其高度、滚动和点击边界；`TaskCockpit` 把身份信息与操作分层，并使 DAG/详情栏在固定主体中等高，事件单独滚动。

**技术栈：** React 18、原生 CSS、Vitest。

**设计：** `docs/superpowers/specs/2026-10-29-任务区垂直会话输出布局.md`

## 全局约束

- 只修改本插件，不修改 DeepSeek Harness 源码。
- 不新增第二个聊天输入框，不发送普通聊天消息。
- 驾驶舱最大高度固定为 `min(55vh, 430px)`；当前会话保留在其下方。
- 所有行为变更先写失败测试，再写最小实现。

## 审查重点

- 面板关闭后不能留下阻挡会话的遮罩或点击层；由任务区样式测试覆盖。
- 窄屏不能压缩 DAG 到不可读；由响应式 CSS 断言覆盖。
- 右栏的长事件不能拉高 DAG；由固定主体和事件滚动样式断言覆盖。
- 无任务或历史无计划任务仍使用同一顶部面板边界；由现有加载状态测试回归覆盖。
- 当前会话输入框不由插件渲染；通过组件树中无聊天输入元素的测试覆盖。
