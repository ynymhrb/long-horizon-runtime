# 拿破仑信件回归包实施计划

> **面向代理工作者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐项实施。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 在 DSH 中以 DeepSeek 子会话运行可中断、可恢复、可验证的 Marmont 密码回归任务。

**架构：** 回归包是固定的版本化契约，资料内容由部署侧受限目录/端点提供而不提交进仓库。运行时以事件驱动的有限研究轮次派发只读任务，使用现有 ArtifactStore 和验收框架保存证据；DeepSeek 路由只能从真实父/子会话记录验证。

**技术栈：** TypeScript、Node SQLite、Vitest、DeepSeek Harness 子会话、现有 ArtifactStore、Cordis/Typert、React 18。

**规格：** `docs/superpowers/specs/2026-10-03-拿破仑信件回归包设计.md`

## 全局约束

- 仅修改 `D:\code\long-horizon-runtime`；不得修改 DeepSeek Harness 源码或用户 profile 配置。
- 资料内容不提交进仓库；启动前校验受限资料的 ID 与 SHA-256，失败即拒绝。
- 只实现 `napoleon_marmont_regression_v1`；不实现 K4、通用研究账本、通用评分策略或自由 DAG 编辑。
- 子会话只能做只读研究工作，并继续带有所有 `long_task_*` 生命周期工具与原生目标工具的拒绝列表。
- 不得以 `dsh --dump-config` 判断模型；实际父/子会话路由不是 DeepSeek 时暂停任务，不产生研究结论。
- 中断和基础设施失败不是内容性反证；无效内容产物必须持久化失败原因，并在预算允许时派发下一轮。
- 每项行为变化先写失败 Vitest 测试；每项任务结束后运行聚焦测试并提交。

## 评审重点

- 资料清单含未登记 URI、空哈希或禁止资料时，绝不可启动任何 DeepSeek 子会话；任务 1 覆盖。
- 父会话未选择 DeepSeek 或子会话记录不符时，必须暂停并留存路由证据；任务 2 覆盖。
- 进程重启后不得重复已经验收通过的轮次，也不得丢失下一轮所需的失败摘要；任务 3 覆盖。
- 仅有模型自述、缺少必需工件或重放失败时，任务不得成功；任务 4 覆盖。
- 浏览器 DTO 只能显示资料 ID、哈希和脱敏摘要，不得泄露资料内容或子会话私有推理；任务 5 覆盖。

## 文件结构

- `src/napoleon-regression.ts`：问题包契约、资料清单校验、轮次状态和必需工件判定。
- `src/dsh-adapters.ts`：提取已启动子会话的实际路由证据，保留现有继承和工具拒绝边界。
- `src/domain.ts`、`src/projections.ts`、`src/event-store.ts`：回归任务字段、追加事件、SQLite 投影与恢复读取。
- `src/runtime.ts`：创建、推进和恢复固定回归轮次，区分内容失败与中断/基础设施失败。
- `src/acceptance.ts`、`src/acceptance-contract.ts`：命名的回归工件/重放/复审验收检查。
- `src/task-ui-api.ts`、`src/remote.ts`、`client/TaskCockpit.js`：紧凑回归摘要及其展示。
