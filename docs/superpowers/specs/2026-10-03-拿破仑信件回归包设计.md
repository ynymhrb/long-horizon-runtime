# 拿破仑信件回归包设计

## 状态与范围

本规格取代“探索性研究运行时设计”作为当前实施范围；后者保留为未来方向的历史设计，不在本期实现。本期只交付一个版本化的拿破仑 Marmont 密码回归包，使用 DeepSeek 作为研究执行模型，以验证 Long Horizon Runtime 能否可靠地持续执行、持久化、恢复和验收一项真实研究工作。

不实现 K4、通用研究假设图、通用研究决策评分、新的 Cockpit 研究界面，也不承诺破解其他历史密码。

## 目标

给定冻结的公开资料和严格预算，运行时驱动 DeepSeek 完成多轮、可中断的 Marmont 密码研究。完成不等于输出译文；它必须生成并保存可重放证据链：

1. 扫描件/转录输入的版本与哈希；
2. 符号账本及规范化规则；
3. 已知映射与其来源；
4. 候选映射搜索的输入、算法版本、随机种子与结果；
5. 去除拿破仑相关语料后的独立复跑；
6. 宿主验证结果及独立复审报告。

## 回归包契约

`NapoleonRegressionPackage` 是版本化、JSON 安全的配置对象：

```text
id: napoleon_marmont_regression_v1
sources: 每项为资料 ID、受限 URI、SHA-256、允许用途
requiredArtifacts: 转录、符号账本、映射表、搜索报告、去语料复跑报告、独立复审
forbiddenSourceIds: 泄露答案与未登记资料
budget: 最大研究轮数、最大子会话数、最大模型调用预算、每轮最长时间
acceptance: 必需工件、哈希检查、可重放命令模板、独立复审量规
```

资料内容不提交进仓库。部署者通过受限的本地资料目录或已注册资料端点提供内容；加载器在启动研究前验证 ID 与 SHA-256。未登记、哈希不符或禁止资料一律拒绝。对外报告只能显示资料 ID、哈希和脱敏摘要。

## 执行循环

研究任务创建时附带此回归包 ID。运行时基于固定研究轮次，而不是一次性生成全部 DAG：每轮向 DeepSeek 提供前轮已验证工件、失败摘要、剩余必需工件和预算，要求只产生下一批只读任务及其产物计划。

```text
冻结资料校验
  -> DeepSeek 规划一轮只读任务
  -> DeepSeek 子会话执行并写候选工件
  -> 宿主执行现有验收检查并固定 evidence bundle
  -> 记录本轮结果与下一轮上下文
  -> 达到工件门槛则独立复审；否则继续或暂停
```

每轮的计划、子会话 ID、输入工件哈希、预算消耗、尝试结果和下一轮提示摘要均追加写入现有事件日志。进程或 DSH 会话停止时，当前尝试按既有中断语义记录；恢复时从最近已验证轮次继续，绝不把中断写作密码分析失败。

当一次内容性尝试未取得有效工件，运行时必须写入失败摘要，并让下一轮 DeepSeek 明确选择一个尚未验证的必需工件或重放/修复步骤。只有预算耗尽、全部必需工件已通过、资料校验失败或现有安全策略要求人工处理时才停止。

## DeepSeek 路由

回归包的规划与执行子会话通过命名执行 profile 路由到 DeepSeek。profile 仅能使用既有的受限 DSH 子会话接口，并继续携带所有 `long_task_*` 生命周期工具和原生目标管理工具的拒绝列表。

实现不得用 `dsh --dump-config` 推断模型路由。验收运行必须从实际创建的 DSH 子会话记录 provider/model 解析结果；若不是 DeepSeek，回归任务立即暂停并报告路由不符，不产生研究结论。

## 验收

宿主验收复用现有声明式验收注册表，不信任 DeepSeek 的成功自述。通过需同时满足：

- 每个 `requiredArtifacts` 均存在、哈希可读且与任务工作区边界一致；
- 转录、符号账本与映射表能被类型化解析；
- 受限重放模板可运行，并生成与声明相符的结果；
- 去语料复跑使用不同的已注册语料配置，结果与主运行在预定容差内一致；
- 独立 DeepSeek 子会话只读取冻结工件与量规，写出结构化复审结论；
- 宿主将验收 bundle 标记为成功。

本期的“独立”指不同 DSH 子会话、不同 attempt、无执行子会话私有推理上下文，并不声称模型权重独立。任一确定性验收失败、资料违规或复审拒绝，均不得将任务标为成功。

## 持久化与展示

新增的窄投影仅记录该回归任务的包 ID、轮次编号、必需工件状态、资料清单摘要、执行路由证据和最终复审状态。`GoalView` / 任务 API 可返回紧凑的 `regression` 摘要；现有 Cockpit 在任务详情中展示轮次、工件清单、路由状态和最终 verdict。它不新增通用研究账本或自由编辑图。

## 验收测试

自动化测试至少覆盖：

- 资料哈希或禁止资料不符时，在启动 DeepSeek 前拒绝；
- 运行时只接受实际路由到 DeepSeek 的执行会话；
- 中断/重启后从最后一轮验证工件恢复，不重复已完成轮次；
- 一轮产生无效工件后保留失败证据并进入下一轮，而非终止；
- 缺少任一必需工件、重放失败或独立复审拒绝时不能成功；
- 使用确定性伪适配器的端到端回归可完整重放，真实 DeepSeek 试运行仅在显式配置且预算可用时执行。

## 交付顺序

1. 回归包契约、资料校验与持久化轮次投影。
2. DeepSeek 固定执行 profile 与运行时单轮/恢复循环。
3. 必需工件、重放与独立复审验收。
4. 紧凑 API/Cockpit 摘要、确定性端到端测试与受控真实试运行。
