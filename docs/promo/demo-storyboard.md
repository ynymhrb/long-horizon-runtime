# Demo 视频/GIF 脚本（45–75 秒）

> 目标：让"用 AI 跑长任务"的人 60 秒内看懂这个插件的杀手剧情——
> **先给计划 → 你确认 → 可视化执行 → 会话断了也不怕 → 回来接着跑**。
> 用真实任务演示，不要用 "foo/bar" 假数据。

## 制作参数

- 录制：OBS（Windows/Linux）或 QuickTime（macOS），1920×1080 或 1280×720。
- 成片：优先发 YouTube / B 站（有声版），同时导出一份无声音 GIF（≤ 8 MB，压缩可用 ffmpeg lossy 调色板）放到 `docs/assets/readme/task-demo.gif` 并嵌入 README 首屏。
- 字幕/大字：视频内关键步骤加 2–3 个字的大标题（如"先给你计划"、"断点续跑"）；GIF 版必须纯画面可懂，不依赖语音。
- 演示前清理屏幕上的个人信息/无关窗口；界面文字调大到可读。

## 分镜

### Scene 0 · 0:00–0:06 —— 开场痛点钩子
- **画面**：浏览器里 DSH 的对话界面，光标在输入框。
- **动作**：粘贴一条真实、够大的任务，例如：
  > "研究 RAG 召回率的影响因素，拆成可验证的子任务，先给我计划，等我确认再执行。"
- **字幕**：`想让 AI 干一件几小时的大事？`

### Scene 1 · 0:06–0:15 —— 计划先行（与默认 agent 的第一个差异点）
- **画面**：模型输出一份编号计划（5–6 个子任务，含依赖说明），Task Area 预览出 DAG。
- **大字**：`先给计划，等你确认` —— 强调**不是直接开跑**。
- **动作**：点"确认执行"。

### Scene 2 · 0:15–0:32 —— 可视化执行
- **画面**：Task Area 中任务逐个从 pending → running → succeeded，DAG 节点变绿；可展示某一步的"结果摘要/验证通过"。
- **大字**：`每一步都能看到进度和结果`。
- **可选加分**：展示某一步失败后自动重试或受阻标红（体现不是黑盒）。

### Scene 3 · 0:32–0:45 —— 中断 → 恢复（全片最重的一场戏）
- **画面 A**：任务跑到 3/6，直接关掉窗口/结束会话（或切到另一个话题）——演示"普通对话早就丢了上下文"。
- **画面 B**：第二天/新会话，输入：
  > "继续 lt_abc123，告诉我还有哪些步骤没完成。"
- **画面 C**：任务原地恢复，**跳过已完成步骤**接着跑。
- **大字**：`会话断了？任务不会丢。`

### Scene 4 · 0:45–0:55 —— 完工 + 可审计
- **画面**：DAG 全绿、最终总结输出；切换到任务的**时间线/历史**视图，展示每一步何时发生、结果如何（审计感）。
- **大字**：`一整条任务，清清楚楚留下记录`。

### Scene 5 · 0:55–1:05 —— 收尾 CTA
- **画面**：黑底大字 + 仓库地址：
  > `github.com/ynymhrb/long-horizon-runtime`
  > `If this saved your agent run — ⭐`
- 中英字幕各留一版（英文版面向 Show HN/Reddit/X，中文版面向 B 站/掘金）。

## 可复用素材清单（剪片子时从仓库取）

- 示例任务/场景：仓库 `examples/`、`scenarios/` 目录下的真实用例。
- 截图底图：`docs/assets/readme/task-dag-completed.png`。
- 真实运行数据：跑一次长时间任务，记录"计划 N 步 → 执行 X 分钟 → 恢复 Y 次 → 全部完成"，放进视频结尾字幕，可信度大增。
